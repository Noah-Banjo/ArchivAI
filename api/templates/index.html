About ArchivAI

Published at iPRES 2025 · Builds on and extends the ARCHANGEL project (UK National Archives / University of Surrey, 2019)

spaCy Named Entity Recognition
Extracts PERSON, ORGANIZATION, PLACE, DATE, LAW, FACILITY, NATIONALITY and more from document text using production-grade NLP.
Blockchain + AI Binding
AI-generated metadata (entities, tags, summary) is cryptographically included in each blockchain transaction — not just the file hash.
PRONOM Format Identification
Every document is identified against The National Archives' PRONOM registry. Persistent Unique Identifiers (PUIDs) assigned on ingest.
PREMIS 3.0 Event Logging
Full preservation lifecycle: ingestion, characterization, message digest calculation, and fixity check events stored in structured PREMIS format.
ICA RiC JSON-LD Export
Each document exposes a /metadata.jsonld endpoint aligned with the Records in Contexts ontology — ready for linked-data catalogue integration.
On-Demand Fixity Checking
Re-hash any stored file at any time and compare against its blockchain record. Every check is logged as a PREMIS fixityCheck event.
